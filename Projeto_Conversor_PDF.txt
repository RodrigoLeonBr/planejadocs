    return 0

Use o comando do CLI para exportar:
   pdf2md obsidian relatorio.pdf --vault ~/Obsidian/Vault
Cada PDF vira um .md com frontmatter YAML (título, tipo, páginas, tags) — o Obsidian lê isso nativamente como metadados pesquisáveis.
